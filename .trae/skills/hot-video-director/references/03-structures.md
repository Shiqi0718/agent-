# 03 脚本与叙事结构

## 1. 通用骨架：H-P-P-T-P-A

| 段 | 作用 | 占比 | 失败表现 |
|---|---|---|---|
| Hook 钩子 | 让人不划走 | 5–10% | 前 3 秒掉一半 |
| Promise 承诺 | 告诉观众"看下去能得到什么" | 10–15% | 观众不知道为什么看 |
| Proof 证明 | 给证据、演示、过程 | 35–45% | 空口说白话 |
| Turn 转折 | 推翻预期或加难度 | 15–20% | 平铺直叙 |
| Payoff 兑现 | 结果、成品、结论 | 15–20% | 承诺没兑现 |
| Action 落点 | 收藏/关注/评论/下单 | 5–10% | 完播但无互动 |

**信息前置还是悬念前置？**
- 教程/干货/带货 → **信息前置**（先说结论，再讲过程），因为用户是来解决问题的。
- 剧情/情感/Vlog → **悬念前置**（先抛反常，后解释），因为用户是来找感觉的。
- 测评 → **结论前置，理由后置**，但结论要留一个"但是"。

## 2. 15 秒（剧情 / 情绪 / 强视觉）

| 时间 | 任务 | 做法 |
|---|---|---|
| 0–2s | 钩子 | 反常动作或一句话，中景/特写 |
| 2–4s | 交代 | 一句话说清谁在哪干嘛，能用画面交代就不说 |
| 4–9s | 升级 | 把观众往错误预期上推，越确信反转越爽 |
| 9–13s | 反转 | 真相与预期相反，但前面有伏笔 |
| 13–15s | 落点 | 一个表情/一句戳心话/一个回环 |

硬约束：单镜头 ≤8s；全片台词 ≤180 字；只允许一个反转。

## 3. 30 秒（口播 / 探店 / 带货）

| 时间 | 任务 | 备注 |
|---|---|---|
| 0–2s | 钩子 | 结果或痛点现场 |
| 2–5s | 承诺 | "看完你会知道…" |
| 5–12s | 第一证据 | 演示、对比、实拍 |
| 12–18s | 转折 | "但真正的问题在这" |
| 18–26s | 第二证据 + 结论 | 给可复用方法/价格/差异 |
| 26–30s | 落点 | 收藏/评论/下单，一句话 |

## 4. 45–60 秒（知识口播 / 测评 / 教程）

| 时间 | 任务 | 备注 |
|---|---|---|
| 0–3s | 钩子 | 反常识或结果前置 |
| 3–6s | 承诺 + 目录 | "3 个设置，第 2 个最关键" |
| 6–18s | 点 1 | 演示 + 一句结论 |
| 18–32s | 点 2 | 全片最高价值点，放中间 |
| 32–45s | 点 3 | 补充或反例 |
| 45–55s | 收束 | 回扣开头，给整体结论 |
| 55–60s | 落点 | 清单/下一条 |

## 5. 3–5 分钟（B站中视频）

| 时间 | 任务 |
|---|---|
| 0–15s | 承诺 + 最强看点（可以是结果、冲突、名场面） |
| 15–45s | 背景只给必要信息，交代"为什么这件事值得看" |
| 45s–2min | 第一段主体，给第一个 Wow Moment |
| 2–3min | 转折/升级，抛出更深的矛盾 |
| 3–4min | 第二段主体 + 最高潮 |
| 4–4.5min | 收束、升华、回扣开头 |
| 4.5–5min | 下期预告/互动 |

B站每 2–3 分钟必须有一个"拉回注意力"的设计：提问、反转、画面突变、章节卡。

## 6. 8–15 分钟（B站深度）

- 结构改用"章节制"：3–5 个章节，每章 2–3 分钟，章节间用统一转场+小标题。
- 开场 30 秒必须回答三件事：讲什么、为什么现在讲、看完能得到什么。
- 每章内部仍是 H-P-P-T-P-A，只是尺度放大。
- 每 2–3 分钟一个钩子；每章结尾留一个悬念接下一章。
- 结尾不要"总结全文"，要给一个**观点**或**选择**，让人想评论。

## 7. 反转设计：A-B-C 公式

```
A：观众看到的表层信息
B：观众自动脑补的预期
C：真相（与 B 相反，但能被 A 里的细节解释）
```

操作顺序（必须倒着来）：
1. 先定 C（真相）。
2. 再想观众会怎么猜 → B。
3. 最后铺 A 和 2–3 个"回看才懂"的伏笔。

伏笔类型：一个多余的动作、一句反常的台词、一个被忽略的道具、一个重复出现的音效。

翻车：先写开头再硬找结尾，十有八九圆不回来；一条塞两个反转，情绪会散。

## 8. 节奏曲线

**快—慢—快**是通用安全牌：

```
0–3s   快：碎切、强音效、信息轰炸
3–25s  慢：让信息落地，镜头 2–4s
25–35s 快：高潮/反转，镜头 0.8–1.5s
结尾    慢：情绪落点，留 1–2s 静帧
```

**叙事势能**：每一段都要比上一段"更近一步"——更具体、更严重、更意外、更接近答案。如果一段没有推进，就是废段。

**预期管理**：钩子承诺 A，正片必须给 A 或更好的 A+。给 B 就是欺骗，7 天长效算法会惩罚。

## 9. 脚本写作规则

1. **一句一口气**：一句话念不完就拆。
2. **口语化**：写"你"，不写"用户"；写"剪",不写"进行剪辑操作"。
3. **字数控制**：口播 4.5–6 字/秒。30s ≈ 135–180 字；60s ≈ 270–360 字。
4. **每句都有功能**：推进、解释、证明、转折、落点。没有功能的句子删。
5. **名词具体**：不写"很快"，写"快 2.7 倍"；不写"很多"，写"37 条"。
6. **不写舞台指示进台词**：动作放"画面"列。
7. **念一遍**：卡壳的地方就是观众会走的地方。

## 10. 分镜表字段（直接用）

| 字段 | 说明 |
|---|---|
| 序号 | 剪辑顺序，不是拍摄顺序 |
| 时间码 | 00:00–00:02 |
| 景别 | 特写/近景/中景/全景/空镜 |
| 画面 | 具体到"谁在做什么" |
| 台词/字幕 | 口语，≤14 字一行 |
| 声音 | 人声/BGM/SFX/环境音 |
| 剪辑动作 | 硬切/J-cut/L-cut/变速/推近 |
| 目的 | 钩子/证明/转折/落点 |

## 11. 单主题与闭环

- **单主题**：一条视频只回答一个问题。出现第二个主题 → 拆成系列，或在结尾说"下一条讲"。
- **闭环**：结尾回到开头的问题/画面/台词，观众会有"完整感"，完播与收藏都会更好。
- **系列化**：固定开场句式 + 固定结尾 + 固定栏目名，是复访率的来源。
