# 05 视听与剪辑工艺

## 1. 节奏：先定镜头时长

### 1.1 分阶段镜头长度（30fps 基准）

| 阶段 | 单镜时长 | 切换频率 |
|---|---|---|
| 钩子 0–3s | 0.6–1.5s | 2–4 个镜头 |
| 承诺 3–8s | 1.5–3s | 2–3 个 |
| 主体 8s–结尾前 | 2–4s | 每 2–3s 一次变化 |
| 情绪点 | 4–6s | 允许停留 |
| 高潮/反转 | 0.5–1.2s | 碎切 |
| 落点结尾 | 2–3s | 静帧或慢推 |

**判断标准**：如果一段连续 5 秒没有任何变化（景别、信息、声音、运动），观众就会开始划。

### 1.2 快—慢—快

```
前 10s：2–4 个镜头，每镜 1–3s
中段：单镜 5–8s，让人消化
最后 5s：加速，镜头 0.8–1.5s
```

静止太久会闷，一直快会累。**变化本身就是节奏**，不是只有"切得快"才叫节奏。

## 2. 剪辑点怎么选

| 方法 | 做法 | 适用 |
|---|---|---|
| 动作中切 | 在动作进行到 30–70% 时切 | 走路、开门、放下杯子 |
| 视线切 | 人物看向画外 → 切到他看的东西 | 建立因果 |
| 声音先入 | 下一镜声音提前 0.3–1s | 转场、换场景 |
| 同构切 | 形状/颜色/运动方向一致 | 高级转场 |
| 静帧切 | 在动作几乎静止的一帧切 | 掩盖跳帧 |
| 跳切 | 同一机位删掉停顿 | 口播去废话 |

**禁忌**：动作方向相反的两镜直接切（左走接右走）会视觉打架；曝光/白平衡不一致的镜头直接切会像穿帮。

## 3. J-cut / L-cut

- **J-cut（声先画后）**：下一镜的声音提前 0.3–1.0s 进入。用于引入新场景、新人物、制造预期。
- **L-cut（画先声后）**：画面切了，上一镜的声音延续 0.3–1.0s。用于展示反应镜头、让台词自然收尾。
- 口播/访谈里，J/L cut 能让"硬切"听起来像一次呼吸。

数字参考：30fps 下 9–30 帧；24fps 下 8–24 帧。

## 4. 转场决策树

```
这个转场要解决什么？
├─ 只是连续 → 硬切（默认）
├─ 时间跳跃 → 叠化 0.2–0.4s / 黑场 0.3s
├─ 空间切换 → 匹配剪辑 或 声音先入
├─ 情绪爆点 → 白闪 2–4 帧 / 抽帧
└─ 章节切换 → 统一转场（全片只用这一种）
```

匹配剪辑四个可匹配元素：**形状、运动方向、主色、声音**。四者至少对上一个。

规则：全片特效转场 ≤2 处。每个镜头都加转场，等于没有转场。

## 5. 变速

| 用途 | 速度 | 备注 |
|---|---|---|
| 强调情绪/细节 | 0.4–0.6x | 配合音效下沉 |
| 教学过程 | 1.5–2x | 剪掉等待，保留关键帧 |
| 转场冲刺 | 3–6x | 0.3s 内完成 |
| 卡点 | 曲线变速 | 重拍瞬间 1x，其余 2x |

注意：
- 慢放素材最好用 60fps 拍摄，30fps 慢放到 0.5x 会顿。
- 变速后音频要单独处理（`atempo` 保持音高）。
- 曲线变速的拐点要落在重拍上，不要悬空。

## 6. 字幕

### 6.1 竖屏（1080×1920）

| 项 | 参数 |
|---|---|
| 字号 | 主字幕 60–76px；强调词 76–92px |
| 行数 | 1 行优先，最多 2 行 |
| 每行字数 | 8–14 字 |
| 位置 | 距底部 320–420px（避开 UI 与手势区） |
| 安全区 | 底部 ≥260px，右侧 ≥140px，顶部 ≥120px |
| 描边 | 2–4px 深色描边 + 轻微投影，保证任何背景可读 |
| 停留 | 每行 0.8–1.6s，按语速 |
| 关键词 | 每句只高亮 1 个词，用色块或变色 |

### 6.2 横屏（1920×1080）

字号 40–56px，距底 80–120px，单行 ≤18 字。

### 6.3 无声可看（静音友好）

- 前 3 秒必须有关键信息字幕。
- 重要信息不能只靠声音：价格、地址、步骤、结论都要上屏。
- 字幕与口播误差 ≤0.15s。
- 不要整段歌词式字幕；只留信息与情绪句。

### 6.4 字幕节奏

- 一句一屏，跟着语义走，不要按字数硬切。
- 转折词单独成屏（"但是""结果""真正的问题是"），给观众一个视觉停顿。
- 数字放大，单位跟上（"2.7 倍""8Mbps"）。

## 7. 声音（三层结构）

| 层 | 电平 | 处理 |
|---|---|---|
| 人声 | 峰值 -6~-3dBFS，平均 -16~-12 LUFS | 降噪 → 高通 80–100Hz → 3–5kHz 提亮 → 压缩 2:1~4:1 |
| BGM | 人声段 -18~-24dB（比人声低 12–18dB） | 侧链压缩 ducking -12dB，起音 50ms，释放 300ms |
| SFX | -12~-6dB | 只用 3–5 种，固定音色形成记忆点 |

**成片**：整体 -14 LUFS，True Peak ≤ -1.5dBTP。

其他硬规则：
- 环境音不要全删，保留 10–20% 让人有现场感。
- 转场处可以做 0.1s 静音，比加"唰"音效高级。
- 卡点不等于每拍都切；只在重拍切。
- 口播句间空白 ≤0.3s，长于 0.5s 就是节奏漏洞。

## 8. 画面

### 8.1 景别与切换

```
远景（建空间）→ 中景（建关系）→ 近景（建情绪）→ 特写（建冲击）
```

不要连续两个同景别硬切；不要全程中景（最平）。

### 8.2 构图

- 竖屏：主体居中偏上 1/3，留出下方字幕区；人物眼睛在画面上 1/3 线。
- 横屏：三分法；访谈留视线空间。
- 背景：干净 > 好看；避免高光斑、杂物、文字。
- 画面张力：对角线、前后景、大小对比、明暗对比。

### 8.3 运镜

推（强调）、拉（揭示）、摇（扫视）、跟（代入）、升降（气势）。手持要有意图，不要无意识抖。

### 8.4 帧冲击

在高潮点用：白闪 2–4 帧、抽帧、缩放 105%→100%、色差 1–2px、轻微镜头抖动。**一条视频只用 1–2 次**。

## 9. 调色

### 9.1 一级校正（先做，必须）
1. 曝光：直方图不贴顶不贴底。
2. 白平衡：肤色为准，别让脸发黄/发青。
3. 对比：黑位压到 5–10，白位 240–250。
4. 饱和度：整体 100–115，肤色单独控。

### 9.2 二级风格
- 统一 LUT，强度 30–60%，不要 100%。
- 冷调（科技/悬疑）：阴影偏青蓝，高光偏中性。
- 暖调（美食/生活）：高光偏橙，阴影偏棕。
- 低饱和（高级感）：整体 -10~-20%，保留肤色。
- 黑金/青橙：只适合特定题材，别全片套。

### 9.3 一致性
同一条视频的所有镜头必须：同一白平衡、同一对比、同一饱和度。跨场景时宁保守勿花。

## 10. 包装

| 元素 | 用法 | 克制原则 |
|---|---|---|
| 标题条 | 前 3s 出现，2–3s 消失 | 只出现一次 |
| 信息卡 | 参数、价格、步骤 | 停留 ≥2.5s 方便截图 |
| 进度条 | 教程/多步骤 | 固定位置，细 |
| 圈注/箭头 | 指向关键细节 | 只在需要时 |
| 贴纸/花字 | 情绪点 | 全片 ≤3 个 |
| 片头动画 | 系列栏目 | ≤1.5s，且不放视频开头 |

## 11. 常见病与处方

| 症状 | 病因 | 处方 |
|---|---|---|
| 看起来"土" | 字体多、颜色杂、描边粗 | 全片 1 种字体、2 种颜色、去掉花字 |
| 看起来"糊" | 码率低、二次压缩、过度锐化 | 1080×1920 / ≥8Mbps / 少锐化 |
| 看起来"平" | 全中景、无对比、无声音层次 | 加特写、加前后景、加 SFX |
| 看起来"吵" | BGM 太满、音效太多 | 人声段 BGM 降到 -20dB，删一半音效 |
| 节奏"拖" | 句间空白、空镜、重复信息 | 每段砍 15%，先砍开头和结尾 |
| 节奏"赶" | 无呼吸、信息过载 | 每 20s 留 1s 静帧或慢镜 |
| 像广告 | 全程产品、无人物、无缺点 | 加真实使用、加一个缺点 |
| 没记忆点 | 无固定开场/结尾/视觉符号 | 固定一句开场 + 固定一个转场音 |

## 12. 帧率与快门

- 常规 30fps，快门 1/60；运动/慢放 60fps，快门 1/120。
- 不要混用帧率；必须混时，统一到时间线帧率再剪。
- 25fps 素材放 30fps 时间线会产生重复帧，运动镜头会顿。
