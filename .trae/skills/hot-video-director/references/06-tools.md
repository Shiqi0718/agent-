# 06 工具矩阵与操作单

> 本文件用于输出"用户照做即可"的操作单。
> 本环境不能启动图形软件；能执行的是 ffmpeg（见 07）。
> 剪映按用户要求**排最后**，并优先免费功能。

## 1. 选型速查

| 需求 | 工具 | 为什么 |
|---|---|---|
| 快速粗剪、批量、自动交付 | ffmpeg / Python | 可脚本化，零会员 |
| 多轨精剪、长视频、多机位 | Premiere Pro | 时间线效率高，生态通用 |
| 电影感调色、肤色、统一 | DaVinci Resolve（免费版够用） | 节点式调色最强 |
| 字幕动效、信息图动画、片头 | After Effects | 关键帧与表达式 |
| 封面、抠图、合成图 | Photoshop | 图层与选区 |
| 矢量图标、版式、印刷 | Illustrator | 矢量 |
| 三维产品/空间字/栏目包装 | C4D + AE | 三维渲染 + 合成 |
| 手机端快发、模板 | 剪映（最后选择） | 模板多，但有 VIP 墙 |

## 2. Premiere Pro

### 2.1 开工设置
1. 新建项目 → 缓存盘放到非系统盘。
2. 新建序列 → 设置：`1080×1920`、`30fps`、方形像素、`48kHz`。
3. 素材箱按 `01_钩子 / 02_主体 / 03_Broll / 04_音频 / 05_包装` 分类。
4. 高码率素材右键 → 代理 → 创建代理（H.264 540p），剪辑完再切回原片。

### 2.2 必背快捷键（Win / Mac）
| 功能 | Win | Mac |
|---|---|---|
| 选择工具 | V | V |
| 剃刀 | C | C |
| 在播放头切断 | Ctrl+K | Cmd+K |
| 波纹删除 | Shift+Delete | Shift+Delete |
| 默认转场 | Ctrl+D | Cmd+D |
| 标记入/出点 | I / O | I / O |
| 插入/覆盖 | , / . | , / . |
| 播放 | Space | Space |
| 逐帧 | ← / → | ← / → |
| 缩放时间线 | + / - | + / - |
| 导出 | Ctrl+M | Cmd+M |
| 新建序列 | Ctrl+N | Cmd+N |

### 2.3 粗剪流程
1. 源监视器打 I/O，只把能用的段落插入时间线。
2. 先按"段落"排序（钩子/主体/转折/落点），不管秒数。
3. `C` 剃刀删废句，`Shift+Delete` 波纹删除。
4. 口播类：删掉所有停顿 >0.4s 的地方，句子之间留 0.2–0.3s。
5. 粗剪完应该比目标时长短 10–15%，给包装留空间。

### 2.4 精剪
- J-cut：把下一段音频往前拖 0.5–1s，用 `Ctrl+K` 切开视频轨。
- L-cut：上一段音频往后延 0.5–1s。
- 动作接：在动作 50% 处切，前后镜运动方向一致。
- 变速：右键 → 速度/持续时间 → 倒放/保持音调；曲线变速用时间重映射。
- 稳定：效果 → 变形稳定器；裁切 5–8% 避免边缘抖动。

### 2.5 字幕
- 首选：`窗口 → 文本 → 转录序列` 自动转写 → 生成字幕 → 批量改样式。
- 样式：字体思源黑体/阿里巴巴普惠体 Bold；60–72px；白字 + 3px 黑描边 + 20% 投影。
- 关键词高亮：单独复制一层，改色 + 加底色块。
- 导出 SRT 备份，方便二次修改。

### 2.6 导出（抖音竖屏）
| 项 | 值 |
|---|---|
| 格式 | H.264 |
| 预设 | 匹配源-高比特率 |
| 分辨率 | 1080×1920 |
| 帧率 | 30（素材 60 则 60） |
| 比特率 | VBR 2 次，目标 10–12 Mbps，最大 16 |
| 音频 | AAC 320kbps，48kHz |
| 色彩 | Rec.709 |
| 其他 | 取消"使用最高渲染质量"以外的多余选项；勾选"使用代理"仅预览时 |

## 3. After Effects

### 3.1 适用场景
- 字幕逐字/逐词弹出、关键词爆炸
- 信息图、数据动画、流程演示
- 片头/栏目包装（≤1.5s）
- 跟踪、抠像、屏幕替换

### 3.2 常用快捷键
`Ctrl+Shift+C` 预合成 ｜ `Ctrl+Y` 纯色层 ｜ `Ctrl+Alt+Y` 调整图层 ｜ `P/S/R/T` 位置/缩放/旋转/不透明度 ｜ `U` 显示所有关键帧 ｜ `M` 蒙版路径 ｜ `F` 蒙版羽化 ｜ `Ctrl+Alt+Home` 锚点居中

### 3.3 三个够用的表达式
```
// 1. 轻微手持抖动
wiggle(2, 8)
// 2. 循环动画
loopOut("cycle")
// 3. 数字递增（配合滑块控制）
Math.round(effect("滑块控制")("滑块"))
```

### 3.4 字幕弹出（最快做法）
1. 文字层 → 动画 → 位置，加 Range Selector。
2. 起始 0% → 100%，缓动 `Easy Ease`，时长 0.25–0.35s。
3. 每个词错开 0.04–0.06s（Offset）。
4. 加 1–2 帧缩放 105%→100%，增加"落点感"。
5. 渲染：`ProRes 4444` + Alpha，导入 PR 叠加。

### 3.5 交接给 PR
- 动态链接：PR 时间线选中片段 → 右键 → 用 After Effects 合成替换。
- 或 AE 渲染 `ProRes 4444 with Alpha`，PR 里直接叠。
- 不要在 AE 里做整片剪辑，效率极低。

## 4. DaVinci Resolve

### 4.1 剪辑页快捷键
`A` 选择 ｜ `B` 刀片 ｜ `I/O` 入出点 ｜ `F9` 插入 ｜ `F10` 覆盖 ｜ `F11` 替换 ｜ `Shift+Delete` 波纹删除 ｜ `N` 吸附开关 ｜ `Ctrl+= / Ctrl+-` 缩放时间线 ｜ `Shift+Z` 适配时间线

### 4.2 调色节点模板（直接照搭）
```
节点 1  Balance    曝光、白平衡、对比
节点 2  Skin       限定器选肤色，降饱和/提亮，羽化 20
节点 3  Look       LUT 或曲线，强度 30–60%
节点 4  Contrast   黑位压 5–10，高光滚降
节点 5  Vignette   窗口 + 羽化，压 10–15%
```

### 4.3 色彩管理
- 项目设置 → 色彩管理 → `DaVinci YRGB Color Managed`。
- 输入：素材对应（Rec.709 / sRGB / LOG）。
- 时间线：`Rec.709 Gamma 2.4`（网络交付）。
- 输出：Rec.709。

### 4.4 交付
- 抖音：自定义 1080×1920，H.264，10–12Mbps，AAC 320。
- B站：1920×1080，H.264 12–16Mbps 或 HEVC。
- 给 PR/AE 交接：导出 `ProRes 422 HQ` 或 XML。

## 5. Photoshop

| 任务 | 操作单 |
|---|---|
| B站封面 | 新建 1146×717，72dpi，RGB；主体占 1/3 以上；右下角留空；导出 PNG <5MB |
| 抖音封面 | 1080×1920；第一屏安全区（上 200 / 下 400 不放关键信息） |
| 抠图 | 选择主体 → 选择并遮住 → 羽化 0.5–1px → 输出蒙版 |
| 信息图 | 8pt 网格；字号层级 96/64/40/28；两种颜色 + 一个强调色 |
| 批量 | 动作 + 批处理；或 `文件 → 脚本 → 图像处理器` |

## 6. Illustrator

- 用途：栏目 LOGO、图标、流程图、矢量信息图、印刷物料。
- 关键：文字转曲前留副本；导出 SVG 给 AE；导出 PNG @2x 给 PR。
- 与 AE 联动：AI 图层可直接导入 AE 并转为形状。

## 7. C4D

**只在三种情况用**：产品三维展示、三维空间字、栏目包装。否则用实拍/AE 更快。

流程：
1. 建模（低模即可，短视频看不清细节）→ 2. 材质（粗糙度比反射重要）→ 3. 三点布光 + 环境光 → 4. 渲染 `OC/RS`，1080×1920，30fps，采样 128–256 → 5. PNG 序列 + Alpha → 6. AE 合成。

时间成本提示：一个 3 秒三维镜头通常比实拍贵 5–10 倍，先问"能不能用 AE 2D 替代"。

## 8. 剪映专业版（最后选择）

### 8.1 免费可达成的效果
| 想要 | 免费做法 |
|---|---|
| 自动字幕 | 识别字幕（基础功能）；或外部生成 SRT 导入 |
| 卡点 | 手动踩点 `Ctrl+J`，不用会员自动卡点 |
| 转场 | 只用"叠化/闪白/硬切"，不用 VIP 特效 |
| 调色 | 调节面板的曲线/HSL；导入免费 LUT |
| 关键帧动画 | 缩放/位置/不透明度打关键帧 |
| 抠像 | 色度抠图（纯色背景） |
| 去水印 | 裁剪或蒙版遮挡，不用 VIP 工具 |
| 变速 | 常规变速 + 曲线变速（基础档） |

### 8.2 快捷键（Win）
`Ctrl+B` 分割 ｜ `Ctrl+Z` 撤销 ｜ `Ctrl+J` 手动踩点 ｜ `Ctrl+滚轮` 缩放时间线 ｜ `空格` 播放 ｜ `Delete` 删除

### 8.3 适合剪映的场景
- 手机拍完要 10 分钟内发。
- 需要口播自动字幕 + 模板封面。
- 团队非专业同事执行。

### 8.4 不适合
- 多轨复杂工程、精细调色、长视频、批量生产。

## 9. 跨软件交接

| 从 → 到 | 格式 | 注意 |
|---|---|---|
| PR → AE | 动态链接 | 工程别改名/移动 |
| AE → PR | ProRes 4444 + Alpha | 色彩空间一致 |
| PR → DaVinci | XML | 特效不保留，只带剪辑点 |
| DaVinci → PR | XML / AAF | 调色需渲染成片 |
| 任意 → 剪映 | 成片 mp4 | 剪映不适合接复杂工程 |
| 任意 → ffmpeg | mp4 / ProRes | 见 07 |

## 10. 学习路径（新手 → 能交付）

1. **第 1 周**：只学"切"和"听"。用 PR 或 ffmpeg 把一条 60s 口播剪到 45s，删掉所有停顿。
2. **第 2 周**：学 J/L cut + 字幕。目标是"听起来像一口气说完"。
3. **第 3 周**：学声音三层 + ducking。目标是人声清楚、BGM 不抢。
4. **第 4 周**：学一级调色 + 统一。目标是三条视频放一起不像三个色调。
5. **第 5 周**：学 AE 字幕弹出 + 信息卡。只学 3 个效果，别铺开。
6. **第 6 周**：完整交付 3 条，走 09 自检表。之后才碰 C4D。

口诀：**先会删，再会接，再会响，再会看，最后才会炫。**
