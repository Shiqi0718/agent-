# 09 交付自检与合规

> 交付前必须走完。任何一项"否"，不交片。

## 1. 前 3 秒（一票否决）

- [ ] 0 秒是**最值钱的一帧**（结果 / 反常 / 冲突 / 成品）？
- [ ] 没有 logo、自我介绍、"大家好"、空镜、黑屏？
- [ ] 1.5 秒内有一句完整的话或一个明确信息？
- [ ] 静音 + 挡住字幕，只看画面，知道有事发生？
- [ ] 钩子承诺的内容，全片真的给了？

## 2. 结构与节奏

- [ ] 一条视频只有一个主题？
- [ ] 5–8 秒内说清了"继续看能得到什么"？
- [ ] 每 8–12 秒有一次变化（信息/景别/声音/视觉）？
- [ ] 单镜头 ≤8 秒（剧情/口播 ≤10 秒）？
- [ ] 每段都比上一段有推进（更具体/更严重/更意外）？
- [ ] 有没有可以整段删掉而不影响理解的段落？有就删。
- [ ] 结尾有落点（情绪 / 清单 / 续集）？

## 3. 字幕

- [ ] 一行 ≤14 字，最多两行？
- [ ] 字号在手机上不费力（勿小于 56px / 1080 宽）？
- [ ] 底部留 ≥260px，右侧留 ≥140px？
- [ ] 字幕与口播误差 ≤0.15s？
- [ ] 价格、地址、步骤、结论都上屏了（不只靠声音）？
- [ ] 关键词每句只高亮 1 个？
- [ ] 没有错别字、没有断句断裂、没有把"的地得"用错？

## 4. 声音

- [ ] 人声峰值 -6~-3dBFS，整体 -14 LUFS？
- [ ] 人声段 BGM 压到 -18~-24dB，不抢字？
- [ ] 句间空白 ≤0.3s（口播）？
- [ ] 没有爆音、喷麦、电流声、突然变大？
- [ ] 环境音保留 10–20%，不闷？
- [ ] 转场处没有突兀的"唰"音效堆叠？

## 5. 画面

- [ ] 所有镜头白平衡/曝光/饱和度一致？
- [ ] 肤色正常，不发黄发青？
- [ ] 没有连续两个同景别硬切？
- [ ] 动作方向不打架（左走接左走）？
- [ ] 竖屏构图主体居中偏上，下方留字幕区？
- [ ] 没有穿帮（麦克风、灯架、手机、杂物）？
- [ ] 码率 ≥8Mbps，1080×1920，无黑边、无拉伸？

## 6. 包装

- [ ] 全片字体 ≤2 种，颜色 ≤3 种？
- [ ] 特效转场 ≤2 处？
- [ ] 贴纸/花字 ≤3 个？
- [ ] 片头动画 ≤1.5 秒，且没占用视频开头？
- [ ] 标题条只出现一次？

## 7. 投放与合规红线

### 通用
- [ ] 没有搬运他人成片当原创（影视解说必须有自己的观点/解说）。
- [ ] 没有"最/第一/唯一/国家级"等绝对化用语。
- [ ] 没有诱导互动（"不转不是中国人""点赞过万就……"）。
- [ ] 没有站外导流黑话（"主页有惊喜""懂的都懂"）。
- [ ] 没有未成年人隐私、他人肖像未授权。
- [ ] 音乐/字体/素材有授权（商用尤其注意）。

### 带货 / 种草
- [ ] 功效表述有依据，不用医疗术语（"治疗""根治""降血糖"等）。
- [ ] 不虚构原价、库存、销量。
- [ ] 对比公平，不贬损竞品。
- [ ] 广告标识合规（如需标注"广告"）。

### 财经 / 医疗 / 法律
- [ ] 不承诺收益、不荐股、不诊断、不提供个案法律意见。
- [ ] 有"仅供参考"类提示。

## 8. 导出参数

| 平台 | 参数 |
|---|---|
| 抖音 | 1080×1920 / H.264 / 10–12Mbps / 30fps / AAC 192k / -14 LUFS |
| B站横屏 | 1920×1080 / H.264 / 12–16Mbps（或 HEVC）/ 30 或 60fps / AAC 320k |
| 封面 | 抖音 1080×1920；B站 1146×717，<5MB |

- [ ] 导出后**完整看一遍**（不是拖进度条）。
- [ ] 手机上看一遍（小屏是最真实的检验）。
- [ ] 文件大小可上传（抖音 >300MB 需分片，尽量压到 300MB 内）。

## 9. 交付位置与命名

用户指定根目录：`D:\Trae work\Trae work处理文件夹`
（沙箱内只能在 `/workspace` 写，结构保持一致）

```
01_素材/        原始素材，只读不改
02_中间文件/    切片、代理、ASS、音频、LUT
03_成片/        <日期>_<平台>_<主题>_v<N>.mp4
04_封面/        <日期>_<平台>_<主题>_v<N>_cover.png
05_说明/        <日期>_<平台>_<主题>_v<N>_notes.md
```

示例：
```
03_成片/20261025_douyin_3个快捷键_v1.mp4
04_封面/20261025_douyin_3个快捷键_v1_cover.png
05_说明/20261025_douyin_3个快捷键_v1_notes.md
```

规则：
- 平台代号只用 `douyin` / `bilibili`。
- 主题 4–8 个中文字，不含空格、斜杠、冒号。
- 改版递增 vN，旧版保留，不覆盖。
- `notes.md` 固定三段：结构说明 / 我替你做的决定 / 可调项。

## 10. 60 秒快检（没时间时的最低标准）

1. 前 3 秒有没有"事"？
2. 声音清不清楚？
3. 字幕有没有挡脸/挡字？
4. 有没有超过 8 秒不动的镜头？
5. 结尾有没有让人想做点什么？
6. 竖屏有没有黑边？

六项全过再发。
