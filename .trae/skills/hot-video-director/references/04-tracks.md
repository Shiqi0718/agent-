# 04 赛道打法（20 类）

> 每条给：**核心指标 / 钩子 / 结构 / 画面与剪辑 / 常见错误**。
> 赛道可叠加（如"探店 + 剧情"），但主赛道只能有一个。

## 1. 知识口播 / 干货
- **核心**：收藏率、5s 留存、复访。
- **钩子**：反常识 + 数字 + 点名人群。例："做口播的，这 3 个设置能省你一小时。"
- **结构**：结论前置 → 3 个点 → 回扣 → 清单。
- **画面**：真人出镜中近景，镜头略低于眼平；每 3–5 秒换一次景别或插入素材画面；关键词大字幕。
- **剪辑**：删掉所有"嗯、那个、就是说"；语速 5–6 字/秒；句间不留超过 0.3s 空白。
- **错误**：把文章念出来；一期讲 5 个点；没有证据只有观点。

## 2. 教程 / 软件操作
- **核心**：完播、收藏、搜索长尾。
- **钩子**：先给成品效果，再倒回去讲步骤。
- **结构**：效果 → 步骤 1/2/3 → 参数表 → 常见坑。
- **画面**：屏幕录制 + 局部放大 + 光标高亮；关键参数必须放大到能看清。
- **剪辑**：1.5–2 倍速剪掉等待；操作与讲解声画同步；每一步开头加序号字幕。
- **错误**：全程录屏不剪辑；参数一闪而过；没有"做完长什么样"。

## 3. 剧情 / 情绪
- **核心**：完播、评论、转发。
- **钩子**：反常动作或一句拧着来的话。
- **结构**：15s 五拍（钩子-交代-升级-反转-落点）。
- **画面**：景别要有落差（全景建关系 → 特写给情绪）；反打镜头；不要全程一个机位。
- **剪辑**：单镜 ≤8s；反转前 0.5s 静音或抽帧；落点留 1s 表情。
- **错误**：前 6 秒交代背景；反转没伏笔；结尾没有情绪落点。

## 4. 搞笑 / 段子
- **核心**：完播、转发、评论。
- **钩子**：荒谬设定直接成立，不解释。
- **结构**：设定 → 升级（每层更荒谬但讲得通）→ 反转（最后 2–3s 一次打掉）。
- **剪辑**：笑点前 0.3s 停顿；音效替代罐头笑声；节奏靠"快-停-快"。
- **错误**：解释笑点；铺垫太长；反转后还继续演。

## 5. 探店
- **核心**：完播、收藏（"下次去"）、POI 转化。
- **钩子**：反差门脸 / 排队长度 / 一口爆汁特写。
- **结构**：钩子 → 价值锚点（价格、分量、对比参照）→ 2–3 道菜沉浸展示 → 地址与行动指令。
- **画面**：进门横移建空间；菜品 45° 俯拍 + 极限特写；环境音保留。
- **剪辑**：菜品镜头 1.5–2.5s，每道菜不超过两句评价；价格用大字幕；最后 3s 给地址。
- **错误**：只拍菜不拍环境；形容词堆砌（"绝了""爱了"）；不报价格。

## 6. 美食 / 做饭
- **核心**：完播、收藏、评论（配方）。
- **钩子**：成品特写 + 一个反常识做法。
- **结构**：成品 → 关键 3 步 → 配方卡 → 试吃反应。
- **画面**：俯拍为主；爆汁/拉丝/冒烟用 60fps 慢放；锅气用侧逆光。
- **剪辑**：ASMR 环境音放大；步骤用 0.8s 快切；配方停留 ≥3s 方便截图。
- **错误**：全程固定机位；步骤跳跃；没有成品镜头。

## 7. Vlog / 生活记录
- **核心**：完播、人设记忆点、粉丝粘性。
- **钩子**：一个具体的生活瞬间或一句自白，不要"记录我的一天"。
- **结构**：一个主题（不是流水账）→ 3–5 个场景 → 一个情绪落点。
- **画面**：手持 + 稳定器交替；多拍空镜和手部特写；保留环境音。
- **剪辑**：按情绪排，不按时间排；转场用动作接或声音接；字幕用口语。
- **错误**：流水账；BGM 盖过人声；没有主题。

## 8. 旅行
- **核心**：完播、收藏、搜索。
- **钩子**：最震撼的一帧 + 一个具体数字（花费/时长/海拔）。
- **结构**：目的地一句话定性 → 3 个必看点 → 避坑 → 路线/花费。
- **画面**：大景别建立空间，再切细节；人物入画做尺度参照；运镜慢。
- **剪辑**：风景镜头 3–5s，信息段 2s 快切；调色统一（同一套 LUT）。
- **错误**：全程航拍无信息；只美不实用；地点不说明。

## 9. 带货 / 种草
- **核心**：点击率、转化率、完播。
- **钩子**：痛点现场 / 效果对比 / 价格反差。
- **结构**：8 选 1 钩子 → ≤8s 效果可视化 → 机制 + 可验证证据 → 价格/福利 → 双指令收口（"点下方 + 现在"）。
- **画面**：真实使用场景；对比要同机位同光线；细节特写证明材质/做工。
- **剪辑**：效果首次出现必须在 8s 内；证据镜头不要美化过度；字幕标价格与规格。
- **错误**：只讲参数不讲场景；夸大功效；CTA 放最后 1 秒。

## 10. 测评 / 开箱
- **核心**：完播、评论（争议）、收藏。
- **钩子**：结论前置 + 一个"但是"。
- **结构**：结论 → 3 个测试维度 → 对比 → 谁该买谁别买。
- **画面**：同机位对比；数据可视化（表格/柱状图）；拆解特写。
- **剪辑**：测试过程 2 倍速；结果用大字幕；保留失败镜头增加可信度。
- **错误**：全是好话；没有对照；数据无来源。

## 11. 职场 / 财经
- **核心**：收藏、复访、评论深度。
- **钩子**：身份点名 + 损失警告 / 反常识结论。
- **结构**：结论 → 依据（数据/案例）→ 反例 → 行动清单。
- **画面**：真人 + 图表；关键数字动画；避免纯 PPT 感。
- **剪辑**：语速稳，信息密度高；每 10s 一个数据点；结论重复一次。
- **错误**：空谈概念；没有数字；合规风险表述（收益承诺、荐股）。

## 12. 科技 / 数码
- **核心**：完播、收藏、搜索。
- **钩子**：极限测试 / 反差结论 / 价格。
- **结构**：结论 → 3 个实测 → 对比表 → 购买建议。
- **画面**：产品特写、屏幕翻拍、跑分录屏；背景干净。
- **剪辑**：参数用动态字幕；对比用分屏；BGM 偏电子。
- **错误**：念参数；没有实拍；画面反光/摩尔纹。

## 13. 美妆 / 穿搭
- **核心**：完播、收藏、转化。
- **钩子**：before/after 同框，或"这个妆我后悔没早学"。
- **结构**：效果 → 3 个关键动作 → 产品/链接 → 适用人群。
- **画面**：正面柔光；肤质特写；穿搭用全身 + 细节。
- **剪辑**：before/after 硬切最有冲击；步骤 1.5s 快切；色温统一。
- **错误**：滤镜过重失真；只拍脸不拍手法；不说明肤质/身材。

## 14. 健身 / 健康
- **核心**：收藏、跟练完成率、复访。
- **钩子**：错误动作对比 / 时间承诺（"每天 8 分钟"）。
- **结构**：错误示范 → 正确动作 → 跟练 → 频率建议。
- **画面**：全身侧面机位；关键关节标注；计时器入画。
- **剪辑**：动作与口令同步；每个动作前 1s 数字倒计时；BGM 节拍 120–140。
- **错误**：动作看不清；没有计时；夸大效果（医疗功效风险）。

## 15. 母婴 / 亲子
- **核心**：完播、收藏、评论。
- **钩子**：真实冲突瞬间 / 一个具体月龄的难题。
- **结构**：场景 → 问题 → 做法 → 结果。
- **画面**：低机位跟拍孩子视角；自然光；保留真实哭声/笑声。
- **剪辑**：不要过度滤镜；字幕大、口语；隐私信息打码。
- **错误**：摆拍感重；育儿建议无依据；暴露孩子隐私。

## 16. 宠物
- **核心**：完播、转发、评论。
- **钩子**：拟人化行为 / 反常反应。
- **结构**：一个行为 → 反应 → 小反转 → 落点。
- **画面**：与宠物同高机位；抓拍；微距特写。
- **剪辑**：保留原声（叫声是钩子）；音效点睛；15–25s 最佳。
- **错误**：配乐盖原声；摆拍；过长。

## 17. 游戏
- **核心**：完播、弹幕、评论。
- **钩子**：高光操作 / 极限翻盘 / 离谱 bug。
- **结构**：高光前置 → 局面解释 → 操作拆解 → 结果。
- **画面**：游戏录屏 + 摄像头反应；关键帧慢放 + 圈注。
- **剪辑**：0.5x 慢放关键 0.5s；音效强化；字幕标技能名。
- **错误**：前 10 秒在加载；全程无解说；高光太晚。

## 18. 音乐 / 舞蹈
- **核心**：完播、转发、二创。
- **钩子**：最强 8 拍 / 一个高难度动作。
- **结构**：高潮前置 → 完整段落 → 教学/拆解 → 循环。
- **画面**：全身景别 + 特写切换；灯光对比强。
- **剪辑**：严格卡拍（每拍 0.5s@120BPM）；动作与重拍对齐；结尾可循环。
- **错误**：卡点不准；机位单一；音画不同步。

## 19. 手工 / 艺术 / 解压
- **核心**：完播、收藏、ASMR。
- **钩子**：极端特写 + 一个反常识材料。
- **结构**：过程延时 → 关键步骤 → 成品展示 → 细节。
- **画面**：微距、侧光；手部为主；背景纯色。
- **剪辑**：延时 + 原声；关键步骤 1s 快切；成品旋转展示。
- **错误**：跳步；没有成品；声音脏。

## 20. 影视解说 / 混剪
- **核心**：完播、评论、完读。
- **钩子**：一个反常识解读 / 名场面。
- **结构**：观点 → 3 段论据（对应片段）→ 回扣观点。
- **画面**：原片片段 + 字幕卡 + 画中画。
- **剪辑**：片段 ≤6s；解说压过原声；关键台词保留原声。
- **错误**：纯搬运；解说念剧情；版权与二创合规风险（需加评论/解说，不能整段搬运）。

## 21. 访谈 / 人物
- **核心**：完播、收藏、评论。
- **钩子**：一句最有冲突的回答，直接放 0 秒。
- **结构**：金句 → 人物背景一句话 → 3 段问答 → 观点落点。
- **画面**：双机位；浅景深；手部与表情特写。
- **剪辑**：J-cut 先入声；删问题保留回答；字幕标身份。
- **错误**：开头自我介绍太长；问答平铺；没有观点。

## 22. 图文 / 口播轮播（抖音图文）
- **核心**：完播（滑动率）、收藏。
- **钩子**：第一张图就是结论。
- **结构**：封面结论 → 3–6 张信息图 → 最后一张清单/CTA。
- **画面**：统一模板，字号 ≥48px，留白足够。
- **剪辑**：每张停留 2–3s；配 BGM；最后一张可截图保存。
- **错误**：字太多；模板不统一；没有结论页。
