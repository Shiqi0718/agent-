# 01 平台机制与数据指标

> 所有阈值均为公开资料与运营经验整理，**不是官方承诺**。以账号后台实际数据为准。
> 2026 年两个平台都在从"短期刺激"转向"长期价值"，这会直接改变剪辑决策。

## 1. 抖音：先想清楚它现在奖励什么

### 1.1 权重排序（2026 经验模型）

```
收藏率 > 复访/回看 > 铁粉深度互动 > 整体停留时长 > 5 秒留存 > 完播率 > 评论质量 > 点赞
```

关键变化：
- **评估周期从 24 小时拉长到 7 天甚至 30 天**。首日爆不等于赢，长尾收藏与回看才决定天花板。
- **点赞权重最低**。只做"爽一下"的内容，数据会好看但没后续流量。
- **账号信任权重**：原创率、真人出镜、稳定输出、粉丝停留，都会进入分发判断。
- 冷启动池通常几百播放，**前 3 秒决定这一轮能不能过**。

### 1.2 对剪辑的直接要求

| 平台要什么 | 剪辑上怎么做 |
|---|---|
| 收藏 | 给出可复用的清单/步骤/模板；在 1/3 处明确说"这条建议存下来" |
| 复访 | 做系列、固定栏目、结尾埋"下一条讲 X" |
| 停留时长 | 信息密度；每 8–12 秒一个变化；删掉所有过渡废话 |
| 5 秒留存 | 0 秒放结果/反差；1.5 秒内说完钩子句 |
| 信任 | 真人出镜、真实场景、少用网图；不要过度包装成广告 |

### 1.3 抖音的"三条命"

1. **3 秒**：能不能留住。
2. **8 秒**：有没有给到继续看的理由（承诺/悬念/利益）。
3. **结尾 3 秒**：有没有情绪落点或互动理由（收藏/评论/看下一条）。

任一环断了，后面再好也没人看到。诊断时按这三刀切。

## 2. B站：另一套尺子

### 2.1 权重（2026 经验模型）

```
完播率 40% > 收藏 25% > 评论 20% > 点赞 10% > 投币/转发 5%
```

补充事实：
- B站公开口径早已强调**播放分钟数**，中长视频不该用抖音的"完播率"尺子量。
- 2026 年推荐从"猜你喜欢"转向"内容理解 + 兴趣扩散"，好内容可以跨标签破圈。
- 新号有 7–14 天冷启动扶持；同类型内容更新过密会被降权。

### 2.2 流量池节奏（经验）

| 阶段 | 时间 | 考核 |
|---|---|---|
| 冷启动 | 1–3h | 前 5 秒留存、完播率（短视频 >45%，3min+ >35%） |
| 算法验证 | 3–7h | 完播率 + 核心受众渗透 |
| 爆发扩散 | 7–24h | 互动密度、弹幕、收藏 |
| 长尾 | 7–60 天 | 搜索、二创、推荐回捞（约 10–15% 内容） |

### 2.3 B站专属剪辑动作

- **前 15 秒必须有"信息承诺"**：这条视频能让你得到什么，说清楚，别只放片头。
- **章节化**：3 分钟以上做 3–5 个段落，每段有小标题/转场，方便拖进度条——B站用户会拖，拖了还愿意回来才算赢。
- **弹幕设计**：预埋 2–3 个"槽点/名场面/金句"，给观众发弹幕的理由。
- **结尾**：不要硬求三连。用"下期做什么，你投票"替代。
- **封面标题**：前半句给搜索，后半句给点击（详见第 6 节）。

## 3. 抖音 vs B站：一张表定生死

| 维度 | 抖音 | B站 |
|---|---|---|
| 画幅 | 9:16 竖屏 | 16:9 横屏为主 |
| 时长 | 15–60s 最稳 | 3–15min 主战场 |
| 核心指标 | 收藏、复访、5s 留存 | 完播、播放分钟、收藏 |
| 用户动作 | 划走成本极低 | 点进来有心理成本 |
| 节奏 | 快、密、每 3s 有变化 | 可慢，但要"有货"，段落感强 |
| 开头 | 直接上最刺激的 | 先给承诺，再给最刺激的 |
| 字幕 | 大、居中偏下、逐句 | 可小，信息型字幕/注释多 |
| 互动 | 评论区、收藏 | 弹幕、投币、收藏 |
| 分发 | 标签 + 兴趣 + 信任 | 内容理解 + 兴趣扩散 + 搜索 |

**同一素材双平台**：不要直接裁。抖音版重做前 3 秒和字幕；B站版补上下文、加章节、换横屏构图。

## 4. 指标 → 剪辑动作（归因表）

| 现象 | 最可能原因 | 先改哪里 |
|---|---|---|
| 3s 留存低 | 钩子弱 / 画面不抓人 | 换 0–1.5s 画面与首句，别改后面 |
| 5s 留存低但 3s 正常 | 承诺不清 / 节奏掉 | 1.5–5s 补一句"你能得到什么" |
| 中段断崖 | 进入铺垫、信息密度下降 | 在断点前 2s 插转折或换景别 |
| 完播高、收藏低 | 爽但无用 | 加清单/步骤/可复用结论 |
| 收藏高、复访低 | 单条好、账号没钩子 | 做系列、结尾埋下一条 |
| 评论低 | 没有可讨论的立场 | 结尾抛一个有争议但安全的问题 |
| 播放高、涨粉低 | 人设不清晰 | 固定开场句式 + 固定视觉记忆点 |
| B站播放高、完播低 | 开头承诺与内容不符 | 重写前 15 秒，别骗点击 |

## 5. 留存曲线诊断法（最实用的一招）

拿到分秒留存曲线，找**第一个斜率突变点**：

- 0–3s 掉 >40%：钩子问题。
- 3–10s 掉 >25%：承诺/信息前置问题。
- 10s–中段缓慢下滑：节奏问题，每 8–12s 加变化。
- 中段突然断崖：某句话/某个镜头劝退，精确到那 1–2 秒删掉。
- 结尾回升：说明结尾有情绪，保留；结尾平掉：加落点或循环设计。

**一次只改一个变量**，否则无法归因。

## 6. 标题与封面

### 抖音
- 标题 = 钩子的文字版，前 10 字必须能独立成立。
- 可用：数字、反差、身份、结果前置、损失警告。
- 不用：夸张到失真、纯标题党（7 天长效下会被反噬）。

### B站
- 封面：**1146×717**（展示裁成 16:9），<5MB，PNG/JPG；右下角避开时长角标。
- 封面原则：人物脸部占比 ≥1/3 且清晰；无人物则主体要大；构图简单；**宁无字勿多字，宁大字勿小字**。
- 标题公式：`搜索词/主题 + 具体承诺或反差`
  - 例：`剪映卡点教程｜3 分钟做出电影感节奏`
  - 例：`我拆了 50 条百万播放，发现钩子只有 6 种`
- 标签：1 个大标签 + 2–3 个精准小标签，别堆无关热词。

## 7. 发布节奏（经验）

| 平台 | 建议 |
|---|---|
| 抖音 | 日更或隔日更；同一模板不要连发 3 条以上 |
| B站 | 每周 1–2 条高质量；同类型过密会降权 |
| 时段 | 早 7–9、午 12–13、晚 18–23；知识类可试工作日 10 点错峰冷启动 |

## 8. 不要做的事

- 不要为了完播率注水、拉长、加无意义空镜。
- 不要搬运/二次剪辑他人成片当原创。
- 不要在同一 Wi-Fi 下互赞互投。
- 不要用"主页有惊喜"等黑话导流。
- 不要堆绝对化用语（最/第一/唯一）和未证实功效，尤其带货。
